# Data-Manager-Toolkit
A Python project developed for my Computer Science coursework at Howard University. This project demonstrates list manipulation, data filtering, searching, and object-oriented programming through a student management toolkit.


Features
- Adds, extends, inserts, and removes list elements
- Searches for student names and tracks occurrences
- Filters and manages grade data
- Implements a StudentList class to organize student records
- Provides a menu-driven application for interactive data management


Technologies Used
- Python


Skills Demonstrated
- List manipulation and data structures
- Data searching and filtering
- Object-oriented programming (OOP)
- Classes, objects, and methods
- User input and output
- Conditional logic and loops
- Interactive application development

  
Project Structure
- part1.py — Basic list operations
- part2.py — Grade filtering and searching
- part3_oop.py — StudentList class implementation
- part4_app.py — Menu-driven data management application

  
How to Run
1. Download or clone the repository.
2. Open the Python scripts in IDLE or another Python environment.
3. Run each script individually, starting with part1.py.
4. Run part4_app.py to interact with the complete Data Manager Toolkit.
